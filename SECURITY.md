# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability, please follow these steps to report it:

1.  **Do not create a public issue.** Security vulnerabilities should be handled discreetly to protect users.
2.  **Email us.** Please send a detailed report to arvindri2005@gmail.com or open a private advisory on GitHub.
3.  **Include details.** Provide as much information as possible, including:
    *   Steps to reproduce the vulnerability.
    *   Affected versions.
    *   Potential impact.

We will acknowledge your report within 48 hours and work with you to address the issue. We appreciate your efforts to make this project more secure!
