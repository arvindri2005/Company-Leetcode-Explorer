# Contributing Guide

Welcome to the team! This document serves as the entry point for contributing to the project.

## Where to Start?

1.  **Set up your environment**: Read [Getting Started](./guide/getting-started.md).
2.  **Understand the codebase**: Read [Project Structure](./guide/project-structure.md).
3.  **Learn the rules**: Read [Coding Standards](./guide/coding-standards.md).

## Workflow

1.  **Pick a task**: workflows are managed via our task tracking system (or GitHub Issues).
2.  **Create a feature branch**: `git checkout -b feature/my-cool-feature`.
3.  **Develop**: Follow the [Feature Development Workflow](./guide/feature-workflow.md).
4.  **Test**: Ensure the app builds and runs correctly.
5.  **Commit**: Use descriptive commit messages.
6.  **Push & PR**: Open a Pull Request for review.

## Questions?

Refer to the specific guide files in the [guide](./guide) directory for detailed information.
